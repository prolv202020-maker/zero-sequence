特殊职业

特殊职业不是“普通职业的更强版本”。它们通常来自罕见觉醒、独特任务、异常适配、个人经历或世界规则回应。强大的同时，也往往伴随更高门槛、更少攻略与更明显的代价。

TYPE 01隐藏主职业
TYPE 02稀有进化职业
TYPE 03独立隐藏力量
TYPE 04法则型特殊培养
重要区分：职业决定主要战斗框架；特殊觉醒改变职业上限；法则决定后期对世界规则的理解；而像「时序遗印」这样的力量，可以独立于主职业存在。拥有特殊职业并不意味着自动比普通职业玩家更强。
HIDDEN MAIN CLASS · GU YANCHE

傀儡师

古言澈 · 隐藏主职业

不属于五大公开基础分支。核心不是单体爆发，而是以多具傀儡、傀儡丝、核心程序、位置控制和战术计算构成多线程战斗体系。

觉醒 → 单傀儡同步 → 多线操控 → 核心傀儡共鸣 → 傀儡领域 → 高阶自主协同
多线操作资源管理战术上限银月
RARE EVOLUTION · SU ZILI

紫月圣女

治疗体系的特殊进化

以治疗师为公开起点，逐渐把治疗、净化、守护和灵域控制融合成一条独有路线。强项不是瞬间爆发伤害，而是在高压战斗中稳定整个团队。

治疗师 → 灵域掌控者 → 紫月圣女
月华治愈紫月净化守护灵域
RARE AWAKENING · LIN LIE

不灭狂战

狂战体系的稀有觉醒

核心「不灭战躯」使林烈在受伤与高压中仍能维持战斗效率，并把伤势转化为战意。但“不灭”不是无敌，超过身体承受极限依然会崩溃。

狂战士 → 狂战领主 → 不灭战神
不灭战躯战意越战越强
RARE EVOLUTION · LUO JIN

无影刺客

刺客体系的虚空进化

从暗影潜行进一步接触空间边界。「虚空潜行」允许罗烬短暂进入空间夹层完成移动和切入，因此对判断、距离与时机要求极高。

刺客 → 影袭者 → 虚空行者 → 暗夜君王
潜行空间边界刺杀
LEGENDARY EVOLUTION · LING TIANYAO

雷霆法皇

雷电术士的传说级进化

「九霄雷印」让雷术从单次输出转变为可叠加、可引爆、可形成雷域的完整体系。后期能够通过雷霆领域影响局部环境。

雷电术士 → 雷霆领主 → 九霄法皇
九霄雷印雷域范围爆发
RARE GUARDIAN · DAI XUANYUE

不屈守护者

盾卫体系的特殊守护进化

核心「玄武壁垒」强调持续承伤、团队防护与阵型稳定。真正价值不是“自己最硬”，而是让整个队伍在本应崩溃的战线上继续站住。

盾卫 → 守城统领 → 不灭壁垒
玄武壁垒援护领域防御
INDEPENDENT HIDDEN POWER · GU CHANGYUAN

时序遗印

不是职业 · 与剑士路线独立

顾长渊公开主职业仍然是剑士。时序遗印来自更深层的时间力量，只在关键时刻作为底牌使用；它不能无限回溯、不能随意预知全部未来，也不能无代价改写过去。

时间感知 → 有限时间干涉 → 时序掌控
时间代价底牌独立成长
LAW SPECIALIZATION · ZHOU FENGYUN

纯运之法则

周逢运「欧皇」· 法则型特殊培养

它不是“想要什么就得到什么”。运之法则只能让原本存在的可能性发生偏移；越随机的事件越容易受到影响，越确定的规则越难被改变。

初运偶然增加，但无法指定事件。
聚运机缘更容易汇聚到身边。
转运在条件成立时偏移概率。
命运共鸣有限触及局部事件的可能性。
限制：规则稳定区会压制效果；幸运可能附带代价；无法让弱者凭运气击败远超自身层级的存在，也不能随意改写必然发生的世界级事件。
概率机缘非万能区域压制
