SPECIAL & HIDDEN CLASS ARCHIVE

特殊隐藏职业
总档案

隐藏主职业从来不是主角团特权。它们是《神魔轮回》世界本身存在的稀有职业分支：可能落在顶级公会手里，也可能被独行玩家、合作队伍、敌对势力、NPC传承者甚至一个无人注意的新手触发。

TYPE 01隐藏主职业
TYPE 02稀有进化职业
TYPE 03独立隐藏力量
TYPE 04极端成长流派
贯穿全剧的硬规则：系统不会因为某人属于顾长渊的队伍，就提高获得隐藏职业的概率。隐藏职业只认条件、适配、选择、任务与世界回应。敌人可以比主角团更早获得，合作势力可以拥有，普通职业玩家也依然可能凭技术、训练和法则领悟击败隐藏职业持有者。
RULE 01

不绑定阵营

主角、敌人、中立、公会、NPC都在同一套规则下获取职业。

RULE 02

稀有不等于唯一

部分隐藏职业可能存在多个持有者，但条件极难重复，成长结果也可能不同。

RULE 03

强力必有代价

资源、身体负担、准备时间、操控难度、反噬或战斗短板至少占一项。

RULE 04

普通职业能登顶

隐藏职业提供不同道路，不提供剧情保送。顶级普通职业玩家仍能成为世界级强者。

HIDDEN MAIN CLASSES

隐藏主职业档案

以下是现阶段世界资料库中已定义的隐藏主职业池。古言澈只是其中一个持有者，其他职业将自然分布到敌对势力、合作队伍、独行玩家与NPC传承中。

07
HIDDEN MAIN CLASS · CONFIRMED HOLDER

傀儡师

已知持有者：古言澈

以傀儡核心、丝线、程序与多线程操控构筑战斗。真正难点不是“召唤更多单位”，而是同时理解多个位置、命令与资源消耗。

觉醒 → 单傀儡同步 → 多线操控 → 核心傀儡共鸣 → 傀儡领域 → 高阶自主协同
获取倾向高逻辑适配、特殊传承、核心傀儡契机
核心代价资源昂贵、精神负荷高、傀儡损毁不可忽视
银月多线操作战术资源管理
HIDDEN MAIN CLASS · WORLD POOL

界碑师

持有者：未公开 · 适合大型势力 / 城防阵营

通过“界碑”固定区域规则、建立安全节点、阻断移动与稳定战场。准备充分时极强，离开自己的界碑网络后战斗力会明显下降。

界碑学徒 → 锚点刻印者 → 领域筑界师 → 万域镇界者
获取倾向古代城防遗迹、律/守/空高适配、长期守城行为
核心代价需要提前布置，机动性弱，界碑被毁会造成反噬
阵地规则锚点城防领域
HIDDEN MAIN CLASS · WORLD POOL

星轨术士

持有者：未公开 · 适合合作队伍 / 情报型玩家

通过星轨、位置与行动轨迹推演战场趋势。它不是预知未来，而是把大量现实信息转换成高精度判断，因此极度依赖观测与计算。

星轨观测者 → 轨迹演算师 → 星图支配者 → 天穹预演者
获取倾向制图、研究、空/时/律适配、特殊观测任务
核心代价信息不足时误差会迅速放大，直接爆发能力有限
轨迹预判团队指挥非预知
HIDDEN MAIN CLASS · WORLD POOL

契兽师

持有者：未公开 · 适合独行者 / 野外势力

与特定魔兽或异界生物建立长期平等契约，共享部分感知与成长。不是“抓宠物”，真正的契约需要双方接受，一旦伙伴死亡或契约崩解，持有者会受到长期影响。

初契者 → 共感驭兽师 → 群契领主 → 万兽共鸣者
获取倾向生/灵高适配、野外长期共处、特殊生物主动认可
核心代价成长依赖伙伴，契约数量受精神与生命承载限制
契约共感魔兽成长共担
HIDDEN MAIN CLASS · WORLD POOL

镜界行者

持有者：未公开 · 可出现于敌对或中立势力

利用镜面、折射角与短暂空间映射改变攻击和感知路径。无法复制他人的职业核心，只能“改写路径”，因此强弱高度取决于地形和使用者判断。

镜行者 → 折光游侠 → 镜域穿行者 → 千镜界主
获取倾向空/迅/律适配、镜界遗迹、极限回避型试炼
核心代价开阔无介质环境较弱，复杂映射容易误伤自己
折射位移路径改写环境依赖
HIDDEN MAIN CLASS · WORLD POOL

遗物使

持有者：未公开 · 适合遗迹组织 / 财团 / NPC传承

能与不同年代、不同体系的古代遗物建立适配连接，短时间调用超出普通装备范畴的能力。职业本身不提供固定强攻技能，实力几乎完全取决于持有的遗物与理解。

遗物感应者 → 遗器共鸣者 → 古代承载者 → 万遗权柄使
获取倾向遗迹探索、灵/律适配、被特定古物认可
核心代价极度依赖装备，遗物之间可能冲突或反噬
古代遗物适配高风险非固定技能树
HIDDEN MAIN CLASS · WORLD POOL

灾咒师

持有者：未公开 · 敌对势力也可自然获得

操控诅咒、弱化、状态累积与污染转移。它不是“邪恶职业”，但玩法天然危险：越强的灾咒越容易在施术者身上留下残留，需要净化、媒介或代价承担。

咒印师 → 灾痕编织者 → 厄域咒主 → 灾厄代行者
获取倾向灵/律高适配、污染区试炼、特殊诅咒幸存者
核心代价反噬、污染累积、对净化职业存在明显克制关系
诅咒削弱污染高风险

RARITY RULE

隐藏主职业到底有多稀有？

  • 不会设定成“全世界只有七个”，否则反而像作者专门给主角团发卡。
  • 真正稀有的是触发条件与适配同时满足：多数玩家一生都不会遇到，遇到了也未必能通过。
  • 同一隐藏职业可以出现第二名持有者，但路线、核心技能和最终形态可能因个人选择而分叉。
  • 顶级势力会主动研究隐藏职业触发条件，因此敌对公会后期拥有多名特殊职业者是合理现象。
  • NPC同样可能拥有玩家系统称之为“隐藏职业”的古老传承，只是他们不会用玩家的面板语言理解它。

RARE EVOLUTION CLASSES

稀有进化职业

主角团多人属于这一类：他们不是开局拿到隐藏主职业，而是从公开职业中走出少见的进化路线。世界其他玩家同样可以出现自己的稀有进化。

EXTREME BUILD · NOT A CLASS

周逢运 · 纯运加点流

周逢运不是隐藏职业持有者。他只是把九大本源属性中的「运」推向极端，因此形成极少见的成长方式。这个例子专门用来证明：即使没有隐藏职业，也能走出全世界独特的玩法。

SERIES-WIDE DOCTRINE

全剧必须贯彻的职业公平原则

主角团不会垄断稀有职业古言澈拥有隐藏主职业，但其他核心成员多数是从普通职业走出的特殊进化。
敌对势力必须有真正强者后续重要敌对公会可以拥有隐藏主职业、稀有进化和极端本源加点者，让冲突来自实力与选择，而不是作者压制。
合作势力也能出现怪物级玩家盟友不只是被主角救的人。他们可以在某些领域比长渊工作室更强，甚至拥有团队无法替代的职业。
NPC不是低配玩家NPC拥有自己的传承、职业历史和强者体系。玩家发现的隐藏职业，有时只是重新命名了NPC早已存在的古老道路。
职业不决定胜负普通剑士、普通盾卫同样可能凭操作、身体训练、装备、法则与经验击败隐藏职业。
隐藏职业也会失败获得稀有职业只是拿到更复杂的道路。错误培养、资源不足、判断失误一样会输，甚至比普通职业付出更大代价。
